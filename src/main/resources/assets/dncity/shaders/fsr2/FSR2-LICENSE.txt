The GLSL shader source in this directory (fsr2_reconstruct.vsh/.fsh and any other .vsh/.fsh files
alongside this license file) is a hand-port from HLSL to GLSL of algorithms from AMD's
FidelityFX Super Resolution 2 (FSR2) reference implementation (ffx_fsr2 / the FSR2 half of the
FidelityFX-FSR3 SDK, https://github.com/GPUOpen-Effects/FidelityFX-FSR2), which is MIT-licensed.
This is a restructuring/port, not a verbatim file-for-file copy -- Minecraft's shader JSON+GLSL
format requires that regardless of license terms. See AGENTS.md's "Architecture: FSR2 temporal
upscaling" section for the specifics of what was ported and from which upstream version/commit
(fill in the exact commit once the actual port is written -- not yet done in this scaffold).
